# TeX Gyre Heros webfonts

TeX Gyre Heros was designed by Bogusław Jackowski and Janusz M. Nowacki. Copyright and distribution terms are provided in `GUST-FONT-LICENSE.txt`, the original README and manifest alongside these files.

The regular and bold WOFF files were repackaged from the unmodified TeX Live 2026 OpenType fonts using fontTools. No outlines, character repertoire or family names were changed. The original family and source distribution are available from the [GUST TeX Gyre project](https://www.gust.org.pl/projects/e-foundry/tex-gyre/heros).
